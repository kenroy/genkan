GENKAN for Obsidian  (v0.9.0)
=============================

Genkan (玄関) is the entryway of a Japanese home: the place you step in. This plugin is the
entryway to your vault, a dashboard homepage with clock, calendar, favourites, tasks, quick note,
web clips, recent notes and search. Works on Mac, Windows, iPhone and iPad.
Needs Obsidian 1.4.0 or newer.

INSTALL (Mac / Windows)
-----------------------
1. Quit Obsidian, or leave it open and reload afterwards.
2. Open your vault folder in Finder / File Explorer.
   The .obsidian folder is hidden:
     Mac:     press Cmd+Shift+.  in Finder to show hidden files
     Windows: View > Show > Hidden items
3. Unzip this package. You get a folder called  genkan.
4. Put that whole folder inside:   <your vault>/.obsidian/plugins/
   (create the "plugins" folder if it doesn't exist).
   You should end up with:
     <your vault>/.obsidian/plugins/genkan/main.js
     <your vault>/.obsidian/plugins/genkan/styles.css
     <your vault>/.obsidian/plugins/genkan/manifest.json
5. In Obsidian: Settings > Community plugins.
   Turn off Restricted mode if it's on, then click the reload icon,
   then switch ON "Genkan".
6. Open it with the home icon in the left ribbon, or press Cmd/Ctrl+P and
   run "Genkan: Open homepage".

INSTALL (iPhone / iPad)
-----------------------
The plugins folder is hidden on iOS, so the easy ways are:
  - Install it on your Mac/PC first and use Obsidian Sync (Settings > Sync >
    turn on "Installed community plugins"), or
  - Put the vault in iCloud Drive and copy the folder in using the Files app
    (Files > iCloud Drive > Obsidian > <vault> > .obsidian > plugins).
Then open Obsidian on the device, go to Settings > Community plugins and
switch ON "Genkan".

FIRST-TIME SETUP
----------------
Settings > Genkan. The defaults work, but you will want to set:
  - Your name           shown in the greeting
  - Web Clipper folder  default "Clippings"
  - Daily notes folder  leave blank to use your Daily Notes settings
Optional: an Unsplash key for nature photos (free at unsplash.com/developers),
Pebble ring notes (off by default; choose whether the ring saves to one main
note, a note you pick, or a separate file per note), and your own Quick Links.

NETWORK USE (all optional, all in the settings)
-----------------------------------------------
Genkan sends none of your notes anywhere. It makes these requests, each of which
can be switched off: a daily quote from ZenQuotes ("Daily quote"), a photo from
Picsum or, if you add a free key, Unsplash ("Photo of the day"), and small site
icons for web clips from Google's favicon service ("Site icons on web clips").
Details are in README.md.

WHERE YOUR DATA LIVES
---------------------
Tasks, the quick note and favourites are plain notes in your vault, in the
folder  genkan/data/  (Tasks.md, Quick Note.md, Favourites.md). They sync
with your vault and you can edit them by hand. Deleting the plugin does not
delete them.

ADDING FAVOURITES
-----------------
Click "+ Add" on the dashboard, or click the star in any note's header.

UPDATING
--------
Replace the three files in the plugin folder with the new ones and reload
Obsidian (Settings > Community plugins > reload, or quit and reopen).

TROUBLESHOOTING
---------------
- Plugin not listed: check the folder is named exactly  genkan
  and sits directly inside  .obsidian/plugins/  (not nested a level deeper).
- Looks wrong after an update: quit Obsidian completely and reopen it.
